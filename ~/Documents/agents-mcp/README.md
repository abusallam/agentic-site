# MCP Servers Collection

This directory contains custom MCP (Model Context Protocol) servers for use with Kiro and other AI assistants.

## Structure

- `servers/` - Individual MCP server implementations
- `configs/` - Configuration files and examples
- `scripts/` - Utility scripts for managing servers
- `docs/` - Documentation for each server

## Getting Started

1. Each server should be in its own subdirectory under `servers/`
2. Include a README.md for each server with setup instructions
3. Test servers locally before adding to your MCP configuration
